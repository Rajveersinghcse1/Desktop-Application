  OPTION 1: DOCKER (RECOMMENDED - EASIEST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🪟 WINDOWS:
   1. Open Command Prompt in this folder
   2. Run: docker-compose up
   3. Done! GUI opens automatically

🐧 LINUX / 🍎 MAC:
   1. Open Terminal in this folder
   2. Run: docker-compose up
   3. Done! GUI opens automatically


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  OPTION 2: LOCAL INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Python (if needed)
   Download Python 3.8-3.11 from https://www.python.org/

STEP 2: Install FFmpeg (if needed)
   🪟 Windows: Download from https://ffmpeg.org/download.html
   🐧 Linux: sudo apt install ffmpeg
   🍎 Mac: brew install ffmpeg

STEP 3: Install Python Packages
   pip install -r requirements.txt

STEP 4: Run Application
   python main.py


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  VERIFY INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run the verification script to check everything is working:

   python verify_setup.py

This will check:
   ✓ Python version
   ✓ Directory structure
   ✓ Core files
   ✓ Dependencies
   ✓ FFmpeg
   ✓ Disk space

  HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SELECT IMAGE
   ┌─────────────────┐
   │ Click "Select   │  → Choose an image file (JPG, PNG)
   │ Image" button   │     Must contain a face
   └─────────────────┘

2. ENTER TEXT
   ┌─────────────────┐
   │ Type your       │  → Enter what the avatar should say
   │ script in the   │     Max 5000 characters
   │ text box        │
   └─────────────────┘

3. CONFIGURE SETTINGS
   ┌─────────────────┐
   │ Voice:          │  → Default / Male / Female
   │ Quality:        │  → Fast / Balanced / High
   │ Resolution:     │  → 480p / 720p / 1080p
   │ Speed:          │  → 0.5x to 2.0x
   └─────────────────┘

4. GENERATE
   ┌─────────────────┐
   │ Click "Generate │  → Wait 2-5 minutes
   │ Avatar Video"   │     Progress shown in status bar
   └─────────────────┘

5. RESULTS
   📁 Output files saved to:
      Docker: ./docker_volumes/output/
      Local:  ./output/

   Files created:
      ✓ avatar_<id>.mp4  (Your video)
      ✓ avatar_<id>.jpg  (Thumbnail)

  FIRST TIME SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

On first run, the application will:
   1. Download AI models (~400 MB)
      ⚠ Requires internet connection
      ⚠ May take 5-10 minutes

   2. Create database structure
   3. Initialize directories

💡 TIP: Use Tools → Download Models to download in advance


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "No face detected"
   → Use a clear, front-facing photo
   → Ensure face is well-lit
   → Try a different image

❌ "FFmpeg not found"
   → Install FFmpeg
   → Add FFmpeg to system PATH
   → Restart terminal/application

❌ "Model download failed"
   → Check internet connection
   → Use Tools → Download Models
   → Check firewall settings

❌ "Out of memory"
   → Close other applications
   → Use "Fast" quality preset
   → Reduce resolution to 480p

❌ Generation takes too long
   → Use "Fast" quality (1-2 min)
   → Lower resolution
   → Enable GPU if available

  TIPS FOR BEST RESULTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📷 Image Tips:
   ✓ Use high-resolution images (1024x1024+)
   ✓ Ensure good lighting
   ✓ Face should be 30-50% of frame
   ✓ Front-facing works best
   ✓ Neutral expression recommended

✍️ Script Tips:
   ✓ Use natural language
   ✓ Include proper punctuation
   ✓ Break into sentences
   ✓ Test with short scripts first

⚙️ Settings Tips:
   ✓ Start with "Balanced" quality
   ✓ Use 720p for most cases
   ✓ Adjust speed for clarity
   ✓ Test different voices
