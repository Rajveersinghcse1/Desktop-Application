## 🎓 Usage Examples

### Quick Start
```bash
# Setup (first time)
python quick_start.py

# Launch GUI
python start.py

# Generate video
python generate_video.py -i photo.jpg -t "Hello world"

# Check health
python health_check.py --fix

# Monitor
python monitor_generation.py --watch
```

### Using Templates
```bash
# List templates
python project_templates.py --list

# Create project
python project_templates.py --create tutorial --output my_video

# Generate from template
cd my_video
# Add photo.jpg
# Edit script.txt
python ../generate_video.py -i photo.jpg -t "$(cat script.txt)"
```

### Docker Usage
```bash
# Build and start
docker-compose up -d

# View logs
docker-compose logs -f

# Access shell
docker exec -it ai-avatar-studio bash

# Stop
docker-compose down
```

## 🔍 Known Issues & Notes

### Minor Issues (Non-Critical)
1. **Unicode Characters in Logs**: Windows console may show encoding warnings for checkmark characters (✓). This is cosmetic only and doesn't affect functionality.

2. **GPU Detection**: No GPU detected on current system. Application falls back to CPU mode automatically. This affects speed but not functionality.

3. **Optional Packages**: Some optional packages (TTS, rembg) not installed. Core functionality works without them.

### Recommendations
1. **Install GPU Support**: For faster processing, install CUDA and GPU-enabled PyTorch
2. **Install Optional Packages**: Run `pip install TTS mediapipe rembg` for full features
3. **Regular Maintenance**: Run cleanup weekly to manage disk space
4. **Backup Projects**: Use backup_manager.py regularly
